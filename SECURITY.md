# Security policy

AI Incident Atlas is a static client-side site with no authentication, backend, secrets, or user accounts.

If you discover a security vulnerability in the site's code or GitHub Actions configuration, do **not** post sensitive exploit details in a public issue. Prefer GitHub's private vulnerability reporting / Security Advisory flow if it is enabled for the repository.

Ordinary broken links, rendering bugs, or incorrect research data should use the normal structured issue forms.

The project intentionally avoids third-party runtime JavaScript libraries and CDNs to reduce supply-chain exposure.
